# Discovery of Nipah virus, Universiti Malaya, 1999

An interactive isometric figure of a virology bench, made with the Anatomy skill. Step through the days to watch Chua Kaw Bing's culture flask, test slide, electron microscope and source sign tell the story.

- `nipah-discovery.html`: open it in any browser (light theme). `nipah-discovery-dark.html` is the dark version.
- `preview.png`: a 1200×1200 still for LinkedIn.
- To rebuild, keep this folder at `anatomy/productions/nipah-discovery` and run `node build.mjs` (add `--dark` for the dark page).

Credit: Chua Kaw Bing, Lam Sai Kit et al., Science 2000.
